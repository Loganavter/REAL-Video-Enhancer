# The L2 pyramid's arithmetic (E29 phase 1)

Measured 2026-11-17 by `scripts/pyramid_budget.py`, CPU only, no GPU job. Reproduces the queue's own
decomposition (8.49 GB logical traffic, 19.7 ms DRAM at 1/3 absorption, 33.1 ms fp16 compute floor,
56.8 ms measured) and adds the two sizes the queue asked about, 1080p and 4K.

The finding is not the buffer size - 7.5 MB and 15.0 MB both fit 32 MiB - but that at BOTH sizes the
compute floor is above the unabsorbed DRAM time, so L2 absorption cannot raise the ceiling above the
compute floor. 1080p: 56.8 ms measured against a 33.1 ms fp16 roofline = 1.72x whatever L2 does.

The 1/3 absorption is an assumption carried from one kernel's ncu sector-hit rate; it is labelled
`ASSUMED` in the record's config and does not change the ceiling.
