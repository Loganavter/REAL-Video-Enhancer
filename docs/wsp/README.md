# Evidence harness (`scripts/harness/`)

The rule this exists for: **a number is not a scalar.** It is `(value, unit, population, instrument,
config, session, n, statistic)`, and the ten retractions in `RESEARCH-LEDGER.md` all came from filling
the missing fields from memory.

Not documentation of a transfer. Three things:

| what | where |
|---|---|
| the harness | `scripts/harness/` — `core` (records), `run` (three-state probes, artifact parsers), `gates` (A/A, bars, claims, coverage), `astcheck`, `cli`, `migrate` |
| the tests | `backend/tests/test_harness_evidence.py` — 42, CPU only, no torch |
| the state of the existing findings | `FINDINGS-DEBT-2026-11-16.md` — generated by `harness.migrate`, not written by hand |

The harness was red-teamed on 2026-11-16: 23 ways a false claim could pass were found, 12 are closed
(unit scale, self-declared bars, unknown-formula derived records, unread CLI directives, migration
laundering through its own output, assumed-as-evidence, `NaN`, population-as-mechanism, kind outside the
item hash, synthetic probes, unkeyed sums, cross-session deltas). The 11 that remain are named in
`rve-harness-redteam-residual-2026-11-16`.


## Run it

```
PYTHONPATH=scripts python3 -m harness.cli scope                            # what is and is not checked
PYTHONPATH=scripts python3 -m harness.migrate "docs/claims-*.txt"         # gate on the existing findings
PYTHONPATH=scripts python3 -m harness.astcheck scripts/harness/*.py       # dead stores, use-before-assignment
python3 -m pytest backend/tests/test_harness_evidence.py -q
```

`harness.migrate` exits non-zero while any decision-bearing finding lacks the tuple. That is the point:
the gate is the debt counter, and it currently reads **0 protected / 211 claims, 62 of them
decision-bearing**.

## The eight classes, and the gate for each

| class | gate |
|---|---|
| a number without its tuple | `Record` refuses to exist without population/instrument/config/session/statistic; relations compare keys, not labels |
| a mechanism named before a discriminating pair | `@cause` needs two records differing in exactly one field |
| leftover from a previous edit → false refusal | A/A before A/B; `refuse()` only against a verified base |
| intent as completion | `run()` waits and kills the group; `probe` is pass/fail/**error**; `ResultsTable` refuses an error row |
| a model of an artifact | parsers with `require()`: "smem" must say static or dynamic, `convs[0]` is read, not recalled |
| a cost model as a measurement | tiers measured/derived/assumed; derived carries formula + inputs and is recomputed |
| one sample as a measurement | `statistic` and the population item-set hash; `below()` compares a bar's `of` and statistic |
| a green check as validation | `Scope.finalize()` refuses green while an expected kind is uncovered; every run prints its own uncovered scope |

## What it does not check, and never will

Whether a population *label* is true; whether the item set is the one the decision needs; whether a cost
model is complete; whether a cited pair rules out the other mechanisms; free-text derivation arithmetic.
The first two are the expensive ones, and they stay human judgements that the harness only makes visible.
